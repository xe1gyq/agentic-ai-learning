# Multi-Agent Systems

This section begins only after the repository has introduced tools, loops, context,
memory, and evaluations. Multiple agents amplify all of those mechanisms; they do not
replace them.

The governing rule is:

> Add agents only when the work contains independent trajectories that can use separate
> context and tool budgets productively.

| Lesson | Architectural question |
|--------|------------------------|
| `01_dynamic_research` | Can an executive expand parallel research from emerging evidence? |

Every lesson must compare the architecture against a simpler baseline and expose its
resource consumption. More agents are a cost to justify, not a maturity badge.
